# Knowledge Base

A personal reference for JavaScript, programming concepts, tools, and learning notes.

## Structure

- `javascript/core/` — language fundamentals (closures, prototypes, async, etc.)
- `javascript/ecosystem/` — npm, bundlers, node, frameworks
- `javascript/snippets/` — copy-paste-able code snippets
- `general/` — cross-language concepts (algorithms, git, design patterns)
- `tools/` — editor configs, CLI tricks, debugging notes
- `learning/` — course notes, book notes, TIL-style entries

## Conventions

- One topic per file, named descriptively (`closures.md`, not `notes3.md`)
- Frontmatter on every file: `tags:` and `date:`
- Flat within each folder — avoid deep nesting
